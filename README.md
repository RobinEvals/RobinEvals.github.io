# The Isle Evrima 皮肤预览器 / Skin Previewer

皮肤预览器网站：[https://robinevals.github.io/](https://robinevals.github.io/)

一开始是卡压测彩色皮肤bug用的，后面因为这个bug不能卡了，于是转向了web渲染自定义皮肤恐龙与私服的皮肤码导入导出。

没什么好说的 纯前端项目 我是懒狗所以更新不是很及时

## 声明

- 所有恐龙模型、贴图、动画资源均来自游戏解包，仅供玩家社区学习与预览使用。

## 当前版本：v0.5.7

## 功能

- 游戏内大部分可玩物种（含解包恐龙）的实时 3D 皮肤预览
- 9 个配色区域 + 眼睛颜色调整
- 游戏内多种 pattern 切换
- CNRE / Nyor's Overlay 皮肤码导入导出
- 渐变生成器与自定义预设，颜色拖放，随机颜色皮肤
- 日夜间模式、背景网格、光照切换
