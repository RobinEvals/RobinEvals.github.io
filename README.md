# The Isle Evrima 皮肤预览器 / Skin Previewer

在线访问：[https://robinevals.github.io/](https://robinevals.github.io/)

## 声明
- 此工具为《The Isle Evrima》玩家皮肤预览器，所有恐龙模型、贴图、Mask 资源均来自游戏解包，仅供玩家社区学习与预览使用。
- 网页前端使用原生 HTML/CSS/JS + Three.js 构建。

## 当前版本：v0.5.7

## 主要功能
- 27 种恐龙实时 3D 皮肤预览
- 9 个配色区域 + 眼睛颜色调整
- 多种 pattern 切换
- 雌雄二态显示（依赖形态键）
- 年龄段形态切换（幼年/亚成年/成年/长老，依赖形态键与动画 clip）
- CNRE / Nyor's Overlay 皮肤码导入导出
- 渐变生成器与自定义预设
- 日夜间模式、背景网格、光照切换
- 渲染截图
