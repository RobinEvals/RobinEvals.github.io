## TI_SkinPreviewer

#### 介绍
声明：此工具主要使用AI制作，非本人编程成果，一切代码均公开开源。Assets里的文件均来自于The Isle Evrima Branch游戏解包。
警告：这个网页版皮肤预览器没有做任何优化，如果你的电脑配置不行，这个编辑器对你来说，会超级不友好
